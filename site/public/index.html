Playbook

生成教程

1. 抓取和选题

从 GitHub Trending、Hacker News、Product Hunt 和扩展技术源抓取候选，默认选择 7 个适合开发者理解的热点。

node scripts/fetch-hot-topics.mjs
2. 历史去重

渲染前读取最近 7 天历史，避开已经播过的项目；如果 GitHub 不够新，就用其他技术源补齐。

node scripts/topic-history.mjs check --days 7
3. 中文口播

把项目价值改写成短视频口吻，使用 Yunxi 神经声音分段配音，并按真实音频时长重建画面节奏。

python scripts/generate-aligned-voiceover.py --voice zh-CN-YunxiNeural --rate=-4%
4. 渲染视频

HyperFrames 生成竖屏视频，最终用 FFmpeg 合成 AAC 音轨，避免画面和口播错位。

npm run render:voiceover
5. 写入网站

成功渲染后导出缩略图和日报数据，新的项目会进入今日列表，历史项目进入可展开归档。

node scripts/export-site-data.mjs --video <mp4> --thumbnail <png>
6. 生成公众号草稿

按当天项目清单生成带结论、项目价值、适合人群和资源 CTA 的公众号图文稿，发布后把文章链接回填到网站。

npm run wechat:generate -- YYYY-MM-DD npm run wechat:manager
7. 可选 API 发布

如果公众号有接口权限和封面素材 ID，可以创建草稿或提交发布；没有权限时仍用管理器复制富文本到后台。

npm run wechat:publish -- --date YYYY-MM-DD --mode draft
8. 发布链接和部署

抖音发布后补视频链接，再部署到 Cloudflare Worker 站点和 radar.bjca.xyz。

npm run site:set-douyin -- YYYY-MM-DD <douyin-url> npm run site:deploy
