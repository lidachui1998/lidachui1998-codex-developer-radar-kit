**它在解决什么：** 多个 Agent 一起工作时，上下文、任务状态和决策散落在不同会话里，协作成本很快超过单 Agent 的收益。

**核心作用：** 用独立通信层串联协作消息，为多 Agent 系统补上可共享、可持续的交流基础设施。
