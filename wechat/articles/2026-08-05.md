**它在解决什么：** Agent 要跑代码时，最难的是给它可持久、可隔离的电脑

**核心作用：** SQLite 保存权威状态，再接容器、Shell 或 JavaScript 后端，适合原型验证。

**你可以怎么用：**

- SQLite 保存权威状态，再接容器、Shell 或 JavaScript 后端，适合原型验证。

- 建议先让Agent 平台与 Workers 沙箱开发者做低成本试用，再决定是否进入正式工作流。

- 把状态和执行后端拆开，Agent 环境更容易恢复和切换，但预览版还不能直接上生产。
