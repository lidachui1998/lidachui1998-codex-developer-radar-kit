## 1. Ghostty
- 来源：GitHub / 现代终端
- 项目：ghostty-org/ghostty
- 热度：GitHub Star 55,584，语言 Zig
- 看点：Ghostty 是一个原生 UI 加 GPU 加速的现代终端，卖点不是炫技，而是每天写代码都能立刻感到顺手。
- 链接：https://github.com/ghostty-org/ghostty
## 2. vaultwarden
- 来源：GitHub / 自建密码库
- 项目：dani-garcia/vaultwarden
- 热度：GitHub Star 61,569，语言 Rust
- 看点：vaultwarden 用 Rust 做了一个轻量 Bitwarden 兼容服务，适合想把密码库掌握在自己服务器上的人。
- 链接：https://github.com/dani-garcia/vaultwarden
## 3. Pi-hole
- 来源：GitHub / 家庭网络
- 项目：pi-hole/pi-hole
- 热度：GitHub Star 59,030，语言 Shell
- 看点：Pi-hole 把广告和追踪拦截放到 DNS 层，一台小机器就能给全家设备做网络清理。
- 链接：https://github.com/pi-hole/pi-hole
## 4. OSV-Scanner
- 来源：GitHub / 供应链安全
- 项目：google/osv-scanner
- 热度：GitHub Star 10,383，语言 Go
- 看点：OSV-Scanner 直接扫依赖漏洞和锁文件，适合放进 CI，把供应链风险提前拦下来。
- 链接：https://github.com/google/osv-scanner
